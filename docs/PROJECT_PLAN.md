# 光研导航 · 项目规划

## 目标

为光学工程研究生提供中文期刊与会议导航，借鉴 CCF-Deadlines 的结构化数据、逐届记录、多轮截止时间和社区 PR 维护方式，独立实现界面。

## 首版范围

1. 会议目录：关键词、方向、地区、投稿状态筛选；普通投稿、PDP、注册、终稿时间线；举办日期与地址；投稿格式、提交方法、发表条件、官网和核心通知链接。
2. 期刊目录：JCR 与中科院独立筛选，纳入至少一种体系有 1/2 区依据的光学及电子、材料交叉期刊；显示年份、学科和证据等级。
3. 新生指南：期刊与会议区别，审稿流程、费用、预印本、重复发表、会议扩展以及报告录用与检索的区别。
4. 开源维护：中英文 README、数据规范、校验与测试、贡献模板、每日来源巡检和 GitHub Pages 部署。

## 数据原则

- 会议记录固定届次；每个事件独立保存类型、日期精度、时区、来源与备注。
- 官方仅公布日期时不擅自补 23:59，不显示秒级倒计时。
- JCR 保存版本年、指标年、类别；由排名推算的分区明确标注。中科院大类、小类与版本分别保存，不用 JCR 或 SJR 替代。
- 官方来源优先；公开第三方分区明确标注“待官方复核”；未知字段为空。
- 不承诺审稿速度、录用率或送检成功，不转载受限分区表或官网全文。
- 自动巡检只发现链接异常或内容变化，人工核实后更新事实与核验日期。

## 实现与验收

React / TypeScript / Vinext 静态导出，JSON 数据独立维护，GitHub Pages 无需后端和 API 密钥。

依次完成来源核实、首个会议页面和本地预览、期刊与指南、关键逻辑测试、生产构建、文档整理和发布配置。测试覆盖时区、日期精度、PDP、分区准入及筛选。主分支部署，PR 校验，每日来源巡检产生可审阅报告。

尚未提供 GitHub 仓库时先交付可发布项目，不声称已上线。首版是可核验的精选目录，后续逐步扩充；维护者每周核实、临近 DDL 加密检查，逐年保留分区来源。
